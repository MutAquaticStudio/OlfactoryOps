# Dravnieks benchmark fixture

This compact test fixture is a verbatim subset of `c_Dravnieks/data.csv` from
the `qian_et_al_2023/predictive_performance` directory in
[`osmoai/publications`](https://github.com/osmoai/publications), commit
`5aa9d2fa98b5d4e133676368c43a9cf65d6f6e04`.

The upstream repository declares its data under CC-BY-4.0. This fixture exists
only to exercise deterministic parsing, group-aware split checks, bounded
training compatibility, and provenance registration. It is not a serving
dataset, a fragrance catalogue, a safety/compliance source, or a production
prediction claim.
